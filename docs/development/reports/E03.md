  `claims`, preserves legacy rows and raw claim enums, and adds exactly the

  `8847dbb72271fa75e9f456502737ebcafe0027f6ac10bfd7ae3757f413e48bcf`.
- Explicit version-selected portability inventories: the accepted 20-table V1
  profile and the 35-table V2 profile, with unique exact inventories,
  per-table schemas/checksums, isolated restore, and open logical export.
  Accepted encrypted E01 V1 package verification and restore remain frozen.
- The package-owned `e03_orchid_station_v1` fictional fixture and only its
  eight frozen operations. Renderer input is limited to operation, preset,
  enum choice, and bounded idempotency key; persisted scenario content and
  stable IDs come from the digest-bound package.
- Canonical V2 source artifacts, locators, reports, observations, assertions,
  claims, temporal assertions, evidence links, multidimensional uncertainty,
  contradictions, unknowns, deterministic immutable personal-model snapshots,
  snapshot diff, correction history, and dependency-aware deletion.
- Five individually named E03 Tauri commands over the accepted framed sidecar.
  Rust retains origin/session/framing checks; Python owns schema, temporal,
  epistemic, correction, deletion, and view-model behavior; the renderer owns
  presentation only.
- A keyboard-operable offline archive surface with fixed capture controls,
  explicit clock selection, source/evidence explorer, snapshot change, and
  deletion preview/confirmation. It contains no streaks, overdue/shame copy,
  completion score, urgency, variable reward, or absence penalty.

## Migrations / data impact

- Externally visible forward migration: `1 -> 2`; no V3/intermediate version
  and no reverse migration claim.
- V1 rows receive deterministic envelope defaults only. `causal` and
  `predictive` are not rewritten; all raw V1 claim origins remain unchanged.
  V2 writes use current domain enums and cannot use V1 `confidence`.
- Migration preconditions check exact V1 inventory, stored migration checksum,
  pending deletion state, legacy claim domains, integrity, and verified
  backup/export authorization when semantic rows exist. Failure occurs before
  mutation; a statement failure rolls the whole migration and bookkeeping back.
- Rollback remains activation/restoration of a retained verified V1 package.
- V1 inventory is exactly 20 tables; V2 inventory is exactly 35 tables.
- Deletion removes exclusive/reconstructive E03 dependencies and snapshots,
  rebuilds the bounded read view, verifies canonical absence, and stores a
  content-free receipt without a stable content hash. External-copy and backup
  retention limits remain visible.
