## Accepted implementation

- One process-local, disposable lexical inverted projection over accepted
  canonical text-bearing records (`source_artifacts`, `reports`, `observations`,
  `assertions`, `claims`, `unknowns`).
- Deterministic lexical ranking: NFKC + case fold + `\w+` tokenization, score =
  total matched-token occurrence count, order = (score desc, matched_terms desc,
  record_id asc), bounded `max_results`.
- Typed `ProjectionManifest` naming builder version, config digest, canonical
  schema version, canonical input identity, policy identity, projection digest and
  status; typed `RetrievalManifest` (forward-compatible with a future
  `ContextManifest`) naming query, purpose, projection, cutoff, selected canonical
  record/version IDs, order/scores, policy identity and retriever version.
- Invalidation: a projection is `STALE` when canonical input identity or policy
  identity differs from the manifest; rebuild is explicit. Correction, E03
  deletion, E08 imported deletion and policy change all mark stale.
- Policy fail-closed: any active non-`local_only`/`never_cloud` policy blocks
  projection and forbids retrieval.
- Counterevidence/contradiction/unknown relations surfaced only from existing
  canonical `record_relations`, `evidence_links` and `contradiction_members`;
  no new claims or similarity-derived relations.
- No-projection/stale/corrupt/blocked states return a typed unavailable outcome;
  canonical archive stays accessible.

## Out of scope

No embeddings, vector/graph/columnar engine, cloud, LLM/neural reranking, new
provider, canonical migration, session/conversation, or `ContextManifest`. No AI
or network authority. Untrusted imported text remains inert searchable data.
