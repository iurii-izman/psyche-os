**REAL_DATA_GATE:** `CLOSED`

## Implemented

- Immutable, versioned `SamplingProtocol` with closed schedule, randomized
  window, prompt/burden, duration, pause/stop, context, missingness, feedback,
  timezone/travel, review and fictional approval fields.
- Ten bounded scheduled events preserve actual observation time, exposure,
  feedback, context and all six missingness states independently.
- Five source-specific sleep records keep diary, actigraphy, consumer wearable,
  clinical test and derived/inferred records distinct. Device-derived rows pin
  maker/model, firmware and algorithm epoch; the consumer value is explicitly
  `black_box_estimate`.
- Two bounded fictional `ConfoundContext` categories preserve source, time,
  uncertainty and version without medical or causal interpretation.
- Deterministic descriptive analysis exposes the exact half-open window,
  denominator, coverage, complete missingness breakdown, source composition,
  protocol/device epochs, feedback exposure, reactivity caution, comparability
  boundaries and limitations. No values are imputed.
- C3 is deliberately disabled. Event-contingent frequency, causal, association,
  clinical, diagnostic, treatment and prediction claims fail closed.
- The only write authority is three fixed named operations over the
  repository-owned fictional Lantern pack. No renderer, CLI, import, network,
  filesystem or arbitrary payload path was added.

## Known limitations

- Only the fixed fictional Lantern pack is writable while the real-data gate is
  closed.
- Output is descriptive C0–C2 only. C3 association, causality, prediction,
  intervention and clinical interpretation are unavailable.
- Event-contingent observations cannot estimate event frequency because E05 has
  no missed-opportunity model.
- Consumer/device output remains source- and algorithm-specific and is not
  clinical truth.
- Rollback is restoration/activation of a retained verified V2 state; no reverse
  migration is claimed.
