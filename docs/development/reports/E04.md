## Implemented

- One canonical immutable assessment governance model replaces the shadowing
  domain/knowledge DTOs while preserving compatibility exports.
- Exact version-addressed identity includes owner, construct, named use,
  population, language/locale, administration mode, recall period and official
  source reference.
- P0-P7 use closed gate/status/reason/review types and deterministic ordered
  evaluation. A failure makes every downstream gate `not_evaluated`.
- All twelve rights decisions are independent `allow`/`deny`/`unknown` values;
  unknown and deny fail closed and no decision grants another capability.
- Lifecycle, review dates, predecessor links, duplicate rejection, legal
  transitions and non-branching immutable history are enforced before mutation.
- A narrow typed register/get/status/list path replaces arbitrary assessment
  schema registration.
- One package-owned fictional metadata entry passes P0 and fails P1. It contains
  no instrument content, response, scoring, norm, cutoff or interpretation data.
