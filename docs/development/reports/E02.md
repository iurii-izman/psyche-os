# E02 — Secure Desktop Shell and Vault Operations UX

**Status:** `IMPLEMENTED`
**Commit:** `candidate branch; see Git history`
**Risk:** `RISK-H`
**Profile:** Windows 11, Tauri 2 / Edge WebView2, synthetic-only
**REAL_DATA_GATE:** `CLOSED`

## Implemented

- A packaged local Tauri shell with a minimal TypeScript/Vite renderer,
  restrictive CSP, explicit local-window command capabilities, denied popups,
  allowlisted navigation, disabled devtools, and no network/listener transport.
- Rust-owned typed commands and a fixed Python sidecar using versioned,
  65,536-byte-bounded JSON frames over inherited stdin/stdout pipes. Unknown
  commands, fields, origins, sessions and state transitions fail closed with
  stable content-free errors.
- Synthetic-only unlock/lock, privacy status, history-preserving correction,
  deletion dry-run/confirmation/limitation receipt, backup health/verification,
  isolated recovery validation, separate activation, and export
  preview/confirmation.
- Backup, restore, activation and encrypted minimum-scope export execute the
  accepted E01 production operations against a disposable fictional vault.
  Paths, SQLCipher/database keys, recovery material and raw failures remain in
  the trusted sidecar and are never returned to the renderer.
- Keyboard-first controls, focus return, labeled fields, associated errors,
  live/non-color status, reduced-motion CSS, and WebView2 renderer accessibility
  enabled for the packaged Windows profile.

## Migrations / data impact

No product schema migration and no real-data admission. Runtime proof creates
only a temporary repository-owned synthetic SQLCipher vault, encrypted backup,
isolated candidate and encrypted export, then removes them when the sidecar
exits. Blob writes and general filesystem authority remain deferred.

## Known limitations

- E02 is a synthetic vertical slice, not real-vault admission. The unlock
  secret establishes only an ephemeral synthetic demonstration session.
- Python secret clearing is best-effort; the packaged sidecar inherits a
  host-owned temporary directory solely for PyInstaller one-file extraction.
- The debug package is unsigned and has no updater; release/signing work is
  explicitly outside E02.
